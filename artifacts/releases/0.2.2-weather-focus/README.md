# Firmware 0.2.2 Weather Focus

Adds a strong focus marker to the on-device weather location editor. The active
input receives a thick accent outline and the prompt names the field currently
connected to the keyboard.

Upload `firmware.bin` through the local OTA page. Keep `firmware.elf` for panic
backtrace decoding. This build compiled successfully but has not been observed
on the physical display.
