# Firmware 0.2.1 Weather Location

Adds the on-device **Weather > Set location** editor. Upload `firmware.bin`
through the firmware's local OTA page. Keep `firmware.elf` for decoding panic
backtraces from this exact build.

This build compiled and passed host tests, but has not been exercised on a
connected ESP32/display.
